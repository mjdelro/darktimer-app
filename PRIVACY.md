# Privacy

darkTimer is a client-side application. The application code does not set
cookies, run analytics, create user accounts, or send recipe selections to a
darkTimer data server.

The site is delivered by a static hosting provider. That provider may process
standard request information such as IP address, user agent, requested path,
and timestamp under its own terms and retention practices.

Opening an external reference, GitHub, or Ko-fi link sends a normal web request
to that third party. Review the third party's privacy terms before following a
link if this concerns you.

This statement describes the application code in this repository. Recheck it
if analytics, remote fonts, APIs, forms, or other network services are added.
