# Contributing

Code, documentation, and recipe-data contributions are accepted under
Apache-2.0. By submitting a contribution, you represent that you have the right
to provide it under those terms.

For recipe data:

1. Use a current manufacturer technical publication whenever possible.
2. Add only the minimum factual fields required by the catalog schema.
3. Record the publisher, title, stable URL, retrieval date, and license basis.
4. Include the agitation method, confidence classification, and any format or EI
   limit needed to interpret the time correctly.
5. Do not scrape or copy a third-party database, prose passage, table, layout,
   user notes, or compilation without a written license that allows repository
   redistribution.
6. Add or update tests for the new source and recipe.

Use a signed-off commit to certify that you created the contribution or have the
right to submit it under these terms:

`Signed-off-by: Your Name <your.email@example.com>`

The project may reject data whose provenance or redistribution basis is unclear.
