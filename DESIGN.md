# darkTimer design direction

Reading this as: a single-purpose darkroom tool for film photographers, styled like a 1970s home-video deck with an amber vacuum-fluorescent display. Dial: ENERGY 2 / RHYTHM 1 / MOTION 2.

- Color: near-black and darker layered charcoal dominate the chassis. Amber is reserved for active numeric data, red marks agitation or decisive actions, and the supplied green VFD canister is the only cool-color instrument graphic.
- Layout: setup is arranged like a VCR front panel; timing mode reduces the interface to the VFD clock, current instruction, and transport controls.
- VFD treatment: DSEG7 Classic supplies true segmented timer, temperature, and time-entry numerals; amber glow is restricted to key numeric readouts so the timer remains the focal point.
- Texture: fine horizontal lines appear only inside display glass to suggest VFD scan structure; the surrounding chassis stays matte.
- Temperature: a compact recessed switch keeps the 68°F default visible and makes the equivalent 20°C label available without changing the recipe.
- Mixing recipe: a smoked display panel separates actionable chemistry volumes from the chassis controls so it can be checked at a glance.
- Recipe variants: the recipe controls expose format, EI, temperature, time, confidence, source, and agitation so the local verified catalog never hides how a time should be interpreted.
- Data trust: the source note, safety warning, and catalog failure state use the same restrained equipment-panel language as the process controls. This keeps legal and safety information visible without turning the app into a generic documentation page.
- Sound: the user-requested speaker icon controls restrained 10-second ticks and a distinct minute-boundary agitation ding; accessible labels preserve clarity without visible text.
- Tank display: the supplied green VFD canister is enlarged inside a recessed 4:3 CRT module occupying roughly one quarter of a desktop viewport. A thick charcoal bezel, convex vignette, faint scan lines, and phosphor-dark glass make it read as a dedicated monitor.
- Tank motion: inside the CRT, the canister rotates around its exact center from −45° to +45° only while agitation is required. It never translates sideways and returns upright during rest.
- Typography: condensed system sans keeps instructions readable; monospaced tabular numerals and equipment labels evoke VCR readouts without sacrificing clarity.
- Spacing: generous touch spacing supports wet or gloved hands, while narrow-screen spacing is tightened to keep the primary action visible.
- Surfaces: charcoal faceplates, dark corner fasteners, recessed selector bays, shallow bevels, inset display glass, and squared transport buttons recall 1970s VCR hardware without relying on bright steel or wood casing.
- Start control: saturated red and a stacked bevel shadow make the enabled Start development button the setup screen's single commit action; its pressed state travels downward like a physical deck button.
- Motion: short state transitions and button feedback stay restrained; continuous motion remains limited to task-critical canister rotation and stops when the timer is paused.
